# VE Addon: DevTools
[Mindustry](https://github.com/Anuken/Mindustry) mod: developer tools add-on for the [Vanilla Expansion](https://github.com/Martian238/Vanilla-Expansion-Mod) (VE)

**English** | [中文](README.zh-CN.md)

## Overview
This mod provides a developer tools add-on for the Vanilla Expansion (VE) mod.  
Please enable the Vanilla Expansion mod before using this addon.

The addon mainly collects world processor groups and world processor schematics related to the VE campaign storyline, providing community map authors and addon developers with references for reuse and further creation.

If you have better designs or suggestions for improvement, contributions and feedback are welcome.
